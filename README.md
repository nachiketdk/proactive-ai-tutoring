# Proactive AI Tutoring for Handwritten Mathematics

Project repository for **Exploring Visual Access and Proactive AI Tutoring for Handwritten Mathematics**.

**Authors:** Nachiket Kotalwar, Conrad Borchers, Shubham Gandhi, Partha Sarathi Purkayastha, David Yaron, and Carolyn P. Rosé.

## Dataset availability

We plan to release the dataset in the coming months, alongside the conference paper. Release updates and access instructions will be posted here.

## Contact

If you are interested in accessing the data before the public release, or have questions about the study or materials, please contact [Nachiket Kotalwar](mailto:nkotalwa@andrew.cmu.edu) to discuss availability and your research needs.
