# Proactive AI Tutoring for Handwritten Mathematics

Project repository for **[Exploring Visual Access and Proactive AI Tutoring for Handwritten Mathematics](https://arxiv.org/abs/2610.26411)**.

**Authors:** Nachiket Kotalwar, Conrad Borchers, Shubham Gandhi, Partha Sarathi Purkayastha, David Yaron, and Carolyn P. Rosé.

## Dataset availability

The [public dataset](https://huggingface.co/datasets/precedentbrute/watching-the-work) includes tutoring conversations, attempts, scores, and 201,882 privacy-screened images of handwritten work from 117 participants. These images are a subset of the 255,984 recorded images described in the paper. Browse linked trajectories in the [interactive explorer](https://huggingface.co/spaces/precedentbrute/watching-the-work).
